## B) „0 Produkte" beheben (sonst leere Paywall / erneute Ablehnung)

StoreKit liefert nur Subscriptions aus, die im Status *Ready to Submit / Waiting for
Review / Approved* sind. Nach der Ablehnung stehen deine Abos auf **Rejected /
Developer Action Needed** → deshalb 0 Produkte auf dem Gerät.

Zu prüfen / zu tun:
1. **Paid Applications Agreement aktiv?** App Store Connect → Verträge, Steuern und
   Bankverbindung → „Paid Apps"-Vertrag muss *Active* sein (nicht „Pending"). Ohne
   aktiven Vertrag lädt KEINE IAP — häufigste Ursache für 0 Produkte.
2. **Jede Subscription** (Plus/Pro Monthly/Yearly) muss haben: Preis, Lokalisierung
   (Anzeigename + Beschreibung), Review-Screenshot. Dann „Bearbeiten" → wieder der
   Version 1.0.2 zuordnen und mit einreichen → Status wird „Waiting for Review",
   Produkte laden wieder.
3. Auf dem Testgerät: mit gültigem Sandbox-/TestFlight-Apple-ID-Account angemeldet.

## D) Wiedervorlage

1. A) + B) erledigen.
2. Sobald die Abos wieder „Waiting for Review" sind: Kaufbildschirm öffnen, Produkte
   laden → **Bildschirmaufnahme** (Preise + Links sichtbar) als Antwort im Resolution
   Center anhängen (Apple bittet ausdrücklich darum).
3. „Erneut zur App-Prüfung übermitteln" — **mit demselben Build 102** (Metadaten-
   Änderung genügt; ein neuer Build ist nicht erforderlich).
